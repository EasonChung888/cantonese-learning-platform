# v0.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create annotated tag `v0.1.0` at the validated product commit and publish a concise, learner-facing GitHub Release.

**Architecture:** Release metadata is immutable around the fixed product snapshot `01e4b2f5938081239d97ab565bf9af6e9c49d69b`. Process documentation is committed and pushed separately on `main`; the annotated tag points to the earlier validated snapshot, and GitHub Release metadata references that tag.

**Tech Stack:** Git, GitHub CLI, Node.js validation scripts

## Global Constraints

- Tag: `v0.1.0`.
- Tag type: annotated Git tag.
- Tag target: `01e4b2f5938081239d97ab565bf9af6e9c49d69b`.
- Tag message: `Cantonese Learning Platform v0.1.0`.
- Release title: `Cantonese Learning Platform v0.1.0 – Initial Public Release`.
- Release type: published full release, not a prerelease or draft.
- Release language: English.
- Release audience: Cantonese learners and ordinary users.
- Never force-update the release tag.

### Task 3: Publish and Verify the GitHub Release

**Files:**
- No files created or modified.

**Interfaces:**
- Consumes: pushed tag `v0.1.0` and the exact approved English notes.
- Produces: a public, published, non-prerelease GitHub Release marked as the latest release.

- [ ] **Step 1: Create the GitHub Release**

Run:

```bash
gh release create v0.1.0 \
  --verify-tag \
  --latest \
  --title 'Cantonese Learning Platform v0.1.0 – Initial Public Release' \
  --notes '## Initial Public Release

Welcome to the first public release of Cantonese Learning Platform, a dependency-free web app for structured Cantonese study. It includes 31 days of Hong Kong–focused learning material and runs directly in a web browser.

## Current Features

- 31 days of structured Cantonese lessons
- Cantonese text, Jyutping, and Mandarin explanations
- Quiz modes for pronunciation, meaning, and reverse recall
- Daily listening practice with recorded sentence audio
- Automatic retry scheduling for unfamiliar cards
- Progress saved locally in the browser
- JSON import and export for moving progress between devices
- Responsive and accessible interface
- No build step or package installation required'
```

Expected: GitHub CLI prints the public Release URL and exits successfully.

- [ ] **Step 2: Verify the published Release metadata**

Run:

```bash

git rev-list -n 1 v0.1.0
git ls-remote --tags origin refs/tags/v0.1.0 refs/tags/v0.1.0^\{\}
git status --short --branch
```

Expected: the tag name is `v0.1.0`, the Release title matches exactly, the URL is public, both status flags are false, `publishedAt` is populated, the tag resolves to the fixed target locally and remotely, and `main` is clean and synchronized.
