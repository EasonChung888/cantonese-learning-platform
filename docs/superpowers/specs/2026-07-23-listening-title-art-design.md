# “听力练习”艺术标题设计

## 目标

把听力练习卡片中的 `h2#listeningTitle` 改为更醒目、带现代海报感的艺术标题。修改只影响“听力练习”四个字，不改变页面总标题、模块按钮、进度徽章、题目内容或交互逻辑。

## 已选视觉方向

采用用户选定的 C 款“现代海报字”：

- 字体使用现有系统无衬线中文字体栈，优先 `PingFang SC` 和 `Hiragino Sans GB`，无须下载网络字体。
- 字重使用粗黑效果，米白色字面配深墨绿色描边。
- 使用朱红色右下错位阴影，形成复古海报套色效果，同时延续网站现有墨绿、米白和朱红配色。
- 字距略微收紧，让四字标题成为一个完整视觉块；标题保持单行。
- 桌面端字号约 `64px`，小屏端最低约 `52px`，比现有最大 `38px` 明显放大。

## 响应式与兼容

- 使用 `clamp()` 控制字号，在桌面与手机间平滑变化。
- 标题保留在现有 `.listening-header` 中；进度徽章继续使用原布局，空间不足时由现有响应式规则移到标题下方。
- 使用 `-webkit-text-stroke` 实现描边，并提供同色文字阴影作为不支持描边时的视觉回退。
- 在手机宽度检查标题、卡片和右侧资料栏均无横向溢出。

## 实施范围

- 只修改 `styles.css` 中 `.listening-header h2` 的字体、字号、字距、填充、描边和阴影。
- 更新 `index.html` 的样式缓存版本，确保本地文件页面刷新后立即载入新效果。
- 不修改 HTML 结构、听力进度状态、播放逻辑、答案逻辑或题目数据。

## 验证

- 在 Day 5 听力练习中确认标题与选定的 C 款预览一致。
- 在桌面与手机宽度检查标题不截断、不换行、无横向滚动。
- 确认进度徽章、播放、显示答案、“认得”和“未熟”仍正常。
- 运行现有听力审计与语法检查，确认此次纯视觉修改没有影响功能。
