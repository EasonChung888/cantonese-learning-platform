# 按书页页码录入技能更新设计

## 目标

更新 `update-cantonese-study-day`，要求教材图片始终按照图片中可见的书页页码升序录入，而不是按照文件名、附件顺序或上传顺序处理。

## 规则

- 先识别每张图片中可见的书页页码，再排序和转录。
- 不以文件名、附件顺序或上传顺序判断页面先后。
- 封面、标题页等无页码页面，依据其与相邻编号页面的内容关系定位。
- 页码不可读且无法由相邻页面可靠确定时，停止猜测并在最终报告中标记不确定性。
- 在完整性检查中确认所有页面已按书页页码顺序检查。

## 修改范围

- 修改技能 `SKILL.md` 的图片检查步骤，加入明确的页码排序规则。
- 修改 `references/day-template.md` 的完整性清单，加入按可见书页页码检查的要求。
- 不修改网站、验证脚本或其他技能行为。

## 验证

运行 `skill-creator` 提供的 `quick_validate.py`，确认技能目录结构和 YAML 元数据仍然有效；随后检查差异，确保没有无关改动。
