# 每日“听力练习”模块设计

## 目标

在每个 Day 的左侧模块导航中增加“听力练习”入口。听力区默认隐藏；选中入口后替换左侧主测验卡片，右侧资料栏保持显示。练习从当前 Day 的全部学习条目中随机抽题，只先播放粤语音频；用户播放音频或主动显示答案后，以“认得”或“未熟”完成自评并进入下一题。

听力练习拥有自己的完成进度、未熟题和会话，不修改原测验的完成数、错题本、熟悉度、重现队列或当前题目。现有主测验的界面和行为保持不变。

## 界面与单题流程

- 在左侧模块导航的末尾增加“听力练习”按钮，并显示当前 Day 的听力题池数量。
- 每次进入 Day 默认选中“全部内容”，听力卡片保持隐藏。点击左侧“听力练习”后，只隐藏原测验卡片，在 `quiz-grid` 左列的相同位置显示听力卡片，并始终保留右侧“卡片资料”和“错题本”。
- 听力模式下隐藏原测验专用的“错题”和“换一题”按钮；点击任何普通模块后恢复原测验区域和这些按钮。
- 卡片标题为“听力练习”，并显示“已认得 X / Y · 待巩固 Z”。其中 Y 是当前 Day 的全部合格条目数。
- 新题初始只显示提示“只听声音，想一想它的意思和粤拼。”、“播放粤语”和“显示答案”按钮，不在可见内容或辅助技术可读内容中提前暴露答案。
- 音频不会自动播放。用户可以在显示答案前后反复播放当前题目；第一次点击播放后立即显示“未熟”和“认得”，但答案仍保持隐藏。
- 点击“显示答案”后，答案区一次性展示：
  - “普通话”：`item.mandarin` 转为简体中文后的内容；
  - “粤语”：`item.cantonese || item.traditional`，沿用网站现有简繁转换，同时保留必要的粤语特有字；
  - “粤拼”：`item.jyutping` 原文。
- 点击“显示答案”也会显示“未熟”和“认得”。用户播放音频或显示答案后即可点击任一按钮记录听力状态并立即进入下一题；不增加独立的“下一题”或跳过按钮。
- 听力答案尚未显示时，右侧资料栏只显示听力进度和操作提示，不暴露答案；显示答案后，右栏同步显示普通话、粤语和粤拼。
- 卡片提供“重置本 Day 听力进度”按钮，只清除当前 Day 的听力状态，其他 Day 及原测验状态不变。
- 播放状态、错误提示和进度变化使用可访问的状态文本；按钮具有明确的中文标签和 `aria-label`。
- 桌面端听力卡片占用主内容区域，移动端将标题、计数和操作按钮纵向排列，避免横向滚动。

## 题池、音频与抽题规则

### 题池

- 题池始终是当前 Day 的全部学习内容，不受左侧当前模块或原测验“错题”模式影响。
- 合格条目必须同时具备音频文本（`cantonese || traditional`）、普通话释义（`mandarin`）和粤拼（`jyutping`）。未来出现字段不完整的条目时将其排除，并在题池为空时显示不可练习状态。
- 当前题库共有 31 个 Day、3,935 条内容，全部满足答案字段要求；其中 2,205 条完整句子均已有同 ID 的 `.m4a` 文件。

### 音频

- 含 `sentenceJyutping` 题型的完整句子优先播放 `audio/sentences/<item.id>.m4a`。
- 其他词语、短语和语音卡使用现有 `SpeechSynthesisUtterance` 路径，语言设为 `zh-HK`，优先粤语或香港中文语音。
- 句子文件播放失败时自动回退到系统粤语语音；系统也无法播放时显示错误，但不改变答案状态、进度或当前题目。
- 听力练习与原测验复用同一播放通道。开始播放新内容时停止上一段录音或语音合成，避免重叠播放。

### 普通轮次

- 当前轮次内，普通题不会重复。
- 普通题随机从尚未出现且不在重现等待期的条目中选择。
- 当前轮次的普通题耗尽后清空该 Day 的 `seen` 列表并开始新轮次；题池多于一项时，新轮次第一题不得与上一轮最后一题相同。
- “认得”的题目仍可在后续新轮次再次出现；进度表示用户当前的自评状态，而不是永久移出题池。

### 未熟重现

- 点击“未熟”会移除该题的听力已认得状态，将其加入听力待巩固集合和重现队列，并把等待间隔随机设为 2 或 3 道普通题。
- 标记“未熟”后立即进入不同题目；只在题池确实只有一项时允许原题继续出现。
- 只有普通、非重现题的出现会将等待计数减一。其他待巩固题的重现不缩短该间隔。
- 等待计数归零后，该题可绕过当前轮次的 `seen` 约束再次出现；出现后重新安排 2–3 道普通题的间隔。
- 点击“认得”会将该题标记为听力已认得，并从听力待巩固集合与重现队列移除。
- 点击“显示答案”本身不改变任何进度。用户必须选择“认得”或“未熟”才能进入下一题。

## 状态与模块边界

### 本地状态

保留现有 `STORAGE_KEY`，在状态对象中新增独立的 `listening` 子结构：

```js
listening: {
  known: { [itemId]: true },
  unfamiliar: { [itemId]: true },
  retry: {
    [itemId]: {
      newCardsUntilDue: 2,
      due: 2,
      repeats: 0
    }
  },
  sessions: {
    [dayId]: {
      seen: [itemId],
      currentItemId: itemId,
      answerRevealed: false,
      assessmentReady: false
    }
  }
}
```

- `known`、`unfamiliar` 和 `retry` 只接受当前题库中的有效 ID。
- `sessions` 只接受 `DAY_ORDER` 中存在的 Day；`seen` 和 `currentItemId` 还必须属于该 Day。
- `assessmentReady` 表示当前题是否已经播放或显示答案；进入下一题时重置为 `false`。旧状态若已展开答案，载入时自动视为可判断。
- 切换 Day、切换左侧模块、刷新页面或重新打开网址时，保留该 Day 尚未完成的听力题、答案展开状态和可判断状态。
- 切换到普通模块会隐藏听力卡片但不会更换听力题；再次点击“听力练习”恢复原题，因为听力题池固定为当天全部内容。
- 重置当前 Day 时，仅删除该 Day 条目在 `known`、`unfamiliar`、`retry` 中的记录及对应 session。

### 导入与导出

- 进度导出格式版本从 1 升至 2，并在原有 `state` 中包含已清理的 `listening` 子结构。
- 导入同时接受版本 1 和版本 2。版本 1 或旧本地状态缺少 `listening` 时使用空听力状态，不影响原进度。
- 合并导入时，听力映射与原进度映射一样以导入内容覆盖同 ID；导入的同 Day session 覆盖当前同 Day session。
- 导入结果提示同时报告原测验已完成/错题数和听力已认得/待巩固数。

### 代码边界

- 新增 `listening-practice.js`，放置纯状态清理、抽题、认得和未熟重现逻辑。该文件不操作 DOM、不读取原测验状态，并通过注入随机函数支持确定性测试。
- 浏览器端通过 `window.CantoneseListening` 使用该引擎；Node 审计脚本通过 CommonJS 导入同一实现，避免测试复制算法。
- `app.js` 只负责把当前 Day、当天题池和 `state.listening` 传给引擎，渲染听力卡片，并复用现有音频播放函数。现有 `makeQuestion`、原测验 retry 逻辑和原测验事件处理不重构。
- `index.html` 在 `data.js` 之后、`app.js` 之前载入新引擎，并为修改过的脚本和样式更新缓存版本。
- `styles.css` 只增加听力卡片及响应式样式，不改变现有测验布局规则。

## 异常与兼容处理

- 当前 session 的题目被后续数据更新移除、移到其他 Day 或字段不再完整时，丢弃该 current/seen 记录并从有效题池选择新题。
- 损坏、数组类型错误、非法计数或不存在的 ID 在载入和导入时被清理；重现等待计数限制为非负整数。
- 当前 Day 没有合格条目时，显示“本 Day 暂无可用的听力内容”，禁用播放、显示答案及自评按钮。
- 听力状态的清理、重置和导入合并不得改写原测验的五类状态字段；实施时也不得覆盖工作区中现有的未提交改动。

## 验证标准

### 自动审计

- 对 `app.js`、`data.js` 和 `listening-practice.js` 运行语法检查。
- 新增 `scripts/audit-listening.js`，载入实际题库和听力引擎并验证：
  - 31 个 Day 的合格题池数量均等于当天全部条目数；
  - 当前 2,205 条句子均存在同 ID 音频文件；
  - 普通题在一轮内不重复，新轮次避免立即重复上一题；
  - “未熟”后立即换题，并且只在 2–3 道普通题后到期；
  - 多个待巩固题互不错误扣减，重现题不计入普通题间隔；
  - “认得”只清理听力待巩固和重现状态；
  - Day session、答案展开状态、播放后可判断状态、重置、旧状态清理及版本 1/2 导入均正确。
- 继续运行现有 retry 审计，确认原测验的 2–3 张普通卡重现行为未发生变化。

### 页面冒烟测试

- 裸网址仍显示首页；进入任意 `#dayN` 后默认显示原测验，左侧出现“听力练习”入口且听力卡片保持隐藏。
- 点击“听力练习”后左侧原测验卡片隐藏，听力卡片在相同位置显示且右侧资料栏保持可见；点击普通模块后正确切回原测验。
- 至少在 Day 1、一个上编章节 Day、一个中编 Day 和一个下编 Day 验证题池、进度与恢复。
- 验证句子录音、非句子系统粤语、句子文件失败回退和完全无法播放提示。
- 验证答案显示前无文字泄露；点击播放后出现“未熟”和“认得”但仍不泄露答案；显示答案后左侧答案区和右侧资料栏的普通话、粤语、粤拼均与当前音频条目一致。
- 验证“未熟”与“认得”的换题和进度更新、当前 Day 重置、Day 切换、刷新恢复、模块切换不重置听力题。
- 比较操作前后的原测验状态，确认听力练习不改变原测验完成数、错题本、重现队列和 session。
- 验证新版进度导出/导入及旧版进度导入；在桌面和手机宽度检查布局与键盘操作。

## 已确认的默认选择

- 听力题池使用当前 Day 的全部学习内容，不跟随左侧模块，也不限于完整句子。
- 听力练习以左侧模块入口切换，不使用独立网址；默认隐藏，选中后替换原测验区域。
- 听力进度与原测验完全分离，但随统一进度文件一起导出和导入。
- 用户播放音频或显示答案后必须选择“认得”或“未熟”才换题；不提供跳过按钮，不自动播放。
- 不生成新的非句子录音文件，沿用网站现有的 `zh-HK` 系统粤语播放路径。
